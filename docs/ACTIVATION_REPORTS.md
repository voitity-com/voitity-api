# Activation reports

Bigmelo records a first-party activation funnel for trial users. The dashboard
exposes the report at `/dashboard/reports` only to users whose role is `admin`.
The API independently checks the role and does not rely on the hidden menu for
authorization.

## Funnel milestones

The ordered funnel is:

1. `trial_started`
2. `profile_created`
3. `avatar_added`
4. `source_synchronized`
5. `profile_published`
6. `whatsapp_added`
7. `product_created`
8. `conversation_started`
9. `link_copied`

Events use idempotency keys for one-time milestones. Conversation events use
the chat identifier, allowing the report to distinguish later between an owner
preview and a public-profile conversation through `metadata.surface`.

No chat text, payment card data, tokens, passwords, source contents, or other
sensitive payloads are stored in `activation_events`.

## Attribution

The public landing preserves `utm_source`, `utm_medium`, `utm_campaign`,
`utm_term`, and `utm_content` on its trial CTA. The admin checkout intent keeps
those values through registration and sign-in. Starting a trial sends the
attribution to the API and stores it on the `trial_started` event. Report
campaign cohorts are anchored to that event.

## API

Both endpoints require Sanctum authentication and an authenticated user with
role `admin`:

- `GET /api/admin/reports/activation`
- `GET /api/admin/reports/activation/users`

Supported filters are `from`, `to`, `campaign`, `source`, and `medium`. The
user endpoint additionally supports `search`, `page`, and `per_page`. Date
ranges are limited to 366 days.

Authenticated profile owners can read their commercial progress and record a
copied link:

- `GET /api/profile/{profile}/activation-progress`
- `POST /api/profile/{profile}/activation-events`

The write endpoint currently accepts only `link_copied`; all other milestones
are generated by authoritative backend operations.

## Default profile features

New profiles enable these profile-scoped features by default when the matching
global feature is available:

- Products
- TikTok
- YouTube
- Other

Product recommendations are also enabled for newly created profiles. Existing
profile-specific choices are not overwritten by the migration.

## Local verification

Run migrations and the focused tests from the API project:

```sh
php artisan migrate
php artisan test --filter=AdminActivationReportControllerTest
php artisan test --filter=ProfileControllerTest::test_user_can_create_a_profile
```

The Postman collection includes an `Admin Reports` folder and local environment
variables for the date range, UTM filters, search, and pagination.
